# SpoitableToolKit 2026.11.0

最初のリリースです。

## 心拍
- Bluetooth（BLE）の心拍計と、Apple Watch の Health Data Server（HDS）から心拍数を受け取ります
- VRChat のアバターへ OSC で送ります（プリセット: VRCHR・VRCOSC）
- 心拍数を記録して、統計とグラフで振り返れます。CSV に書き出せます
- WebSocket で配信して、配信ソフトのオーバーレイに出せます

## 動画 URL
- VRChat で再生できなかった動画の URL を、再生できる形にしてコピーします（yt-dlp を使います。外のサーバーに任せることもできます）

## VRChat のログ
- VRChat のログから、入室・退室・ワールド・動画の再生などの出来事を一覧にします。検索・絞り込み・日時での遡りができます

## VR
- 手首を見るとショートカットバーが表示されます。心拍数や時刻を確認したり、ショートカットから画面を開いたりできます
- アプリの画面を VR ウィンドウで開けます（手首の上に表示するか、目の前の空間に配置するかを選べます）

## モジュール
- GitHub のリリースやソースから、モジュールを追加・更新できます
- モジュールを作るための SDK を同梱しています

## アプリの更新
- 新しいバージョンがあると、画面の上に知らせが出ます。「更新」を押すとダウンロードしてインストールし、再起動します
- 更新のチャンネル（Stable / Nightly）を設定で選べます
